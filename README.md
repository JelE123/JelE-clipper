# JelE Clipper

From stream to short. A local app that goes through your Twitch streams (OBS recordings), finds the best
moments and turns them into TikTok, Shorts and Reels videos, with captions, effects and your own brand.

## Install
1. Download `JelE_update.zip` from the latest [release](../../releases/latest).
2. Extract it over `C:\` (you get `C:\JelE\clipper\...`).
3. Run `C:\JelE\clipper\install.bat`, then `start.bat`.
4. Fill in your OBS password and Twitch name in the app under Settings > Keys.

After that, new versions come in by themselves through Settings > Updates.

## Privacy
This repository only holds the Clipper app: no passwords, keys, personal names or stream assets.
Your keys are stored on your own PC only (`C:\JelE\mascotte\config.js`, filled in through Settings > Keys),
and that file never goes to GitHub. Every release is checked automatically for keys and email addresses first.
